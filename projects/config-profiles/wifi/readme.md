# Wifi Profiles on Intune Windows 10

This is Intunes solution for deploying wifi profiles. It allows users in an organization to seamlessly access wifi.
To use it, I went to settings catalog, created a wifi profile and assigned it to my Device group Win Devices:
This profile would be used as part zero touch device plan
